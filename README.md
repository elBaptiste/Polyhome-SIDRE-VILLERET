# Projet Polyhome

## Fonctionnalités du barème
* **Comptes :** Création et connexion des utilisateurs.
* **Périphériques :** Liste dynamique et envoi de commandes (volets/lumières).

## Améliorations & Bonus
* **Simplification :** Sauvegarde locale du token pour éviter de se reconnecter.
* **Actions groupées :** Boutons pour piloter tous les équipements d'un coup.
* **Gestion des accès :** Ajout d'utilisateurs et gestion d'accès temporaires à une maison.
* **Programmation horaire :** Système de choix d'heure automatique pour ouvrir/fermer les volets (sauvegardé par maison).
    * *Note : Fonctionne via l'application ouverte, pas encore de gestion en arrière-plan (Background Service).*
